# Software Project

A full-stack event management web application with a frontend built using HTML, CSS, and JavaScript, and a Node.js/Express backend connected to MongoDB.

## Features

- User registration and login
- User authentication
- Event management
- Event services and details
- Concerts and festivals
- Corporate events
- Event strategy and planning
- On-site production
- Design and branding services
- Gallery and reviews
- Contact and service pages
- MongoDB database integration
